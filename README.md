# Quotex Candle Analysis — Android starter

বাংলা Android অ্যাপের প্রাথমিক সংস্করণ। চার্টের স্ক্রিনশট ফোনে নির্বাচন করে একটি সাধারণ লাল/সবুজ পিক্সেল-ভিত্তিক ভিজ্যুয়াল ইঙ্গিত দেখা যায়।

## Features
- ফোন থেকে চার্টের স্ক্রিনশট নির্বাচন ও প্রিভিউ।
- আনুমানিক সবুজ/লাল পিক্সেল গণনা এবং সতর্ক ভিজ্যুয়াল ঝোঁক।
- বাংলা ম্যানুয়াল চার্ট যাচাই তালিকা।
- কোনো Quotex লগইন/পাসওয়ার্ড লাগে না; অ্যাপ স্বয়ংক্রিয় ট্রেড করে না।
- স্ক্রিনশট ডিভাইসেই প্রসেস হয়, সার্ভারে আপলোড হয় না।

## Build APK
1. GitHub-এর Actions ট্যাবে যান।
2. **Build Quotex Candle Analysis APK** workflow খুলুন।
3. **Run workflow** চাপুন অথবা নতুন commit-এর পর build শেষ হওয়ার অপেক্ষা করুন।
4. সফল run খুলে Artifacts থেকে `Quotex-Candle-Analysis-debug-apk` ডাউনলোড করুন। এতে `app-debug.apk` থাকবে।

## Limitations
এই প্রোটোটাইপ পুরো স্ক্রিনশটে লাল/সবুজ পিক্সেল গোনে; ক্যান্ডেল আলাদা করে শনাক্ত করে না এবং প্রকৃত OHLC ডেটা বের করে না। চার্টের থিম, ইন্ডিকেটর ও বোতাম ফলকে প্রভাবিত করতে পারে। লাইভ Quotex OTC ডেটা যুক্ত নেই; কোনো CALL/PUT ফল যাচাইকৃত সম্ভাব্যতা বা লাভের নিশ্চয়তা নয়। বাস্তব ট্রেডের আগে নিজে যাচাই করুন এবং ডেমোতে পরীক্ষা করুন। এটি আর্থিক পরামর্শ নয়।
